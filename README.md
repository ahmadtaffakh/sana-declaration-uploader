# Sana Declaration Uploader

ابزار مستقل و تک‌کاربره برای آماده‌سازی و ثبت اظهارنامه در سامانهٔ ثنا.

## وضعیت فعلی

این نسخه هستهٔ امن و قابل‌آزمون پروژه و قرارداد Word نسخهٔ اول را فراهم می‌کند:

- مدل ورودی اظهارنامه و پیوست‌ها؛
- اعتبارسنجی fail-closed؛
- الزام تأیید صریح اپراتور پیش از عملیات زنده؛
- parser قالب Word گروهی با شرح و پیوست مشترک، گروهی و اختصاصی؛
- قرارداد نسخهٔ ۲ پیوست شامل شماره مدرک، تاریخ مدرک و وضعیت نمایش برای مخاطب؛
- نگاشت fail-closed نام شغل، موقعیت و واحد قضایی به شناسه‌های سایت؛
- ورود آزمایشی و fail-closed به خودکاربری با Playwright؛
- ناوبری فرم جدید تا مرحلهٔ انتخاب نوع مخاطب، بدون ذخیره یا ثبت؛
- انتخاب دقیق موضوع، دلیل «سایر دلایل و مستندات» و ثبت متن شرح؛
- آداپتور سه مرحلهٔ مشاهده‌شدهٔ پیوست: ثبت، بارگذاری و تأیید اصالت.
- کنترل آمادگی امضا و گیت مستقل تأیید ثبت نهایی؛
- استخراج یکتای کد رهگیری و ذخیرهٔ اتمیک نتیجه کنار همان ورودی.

کلیک امضای نهایی فقط از API داخلی و با تأیید مستقل همان لحظه مجاز است؛ هنوز به
CLI متصل نشده تا ثبت ناخواسته رخ ندهد. parser و فرمان `inspect` هیچ عملیات
زنده‌ای انجام نمی‌دهند.

## قالب ورودی

فایل `templates/declaration-batch-template.docx` را با نام `declaration.docx`
داخل یک پوشهٔ مستقل کپی کنید. فایل‌های پیوست باید در زیرپوشهٔ `attachments`
همان پوشه قرار گیرند.

هر مخاطب می‌تواند از اطلاعات دستی یا شماره ابلاغیه استفاده کند. شرح‌ها می‌توانند
مشترک، وابسته به یک الگو، پارامتری یا کاملاً اختصاصی باشند. پیوست‌ها نیز دامنهٔ
مشترک، الگو یا مخاطب دارند.

مقادیر عددی سایت در Word حدس زده نمی‌شوند. فهرست‌های تأییدشده مطابق قرارداد
`lookups/README.md` نگهداری می‌شوند.

## اصول ایمنی

- رمز، OTP، cookie و token داخل کد، فایل تنظیمات یا log ذخیره نمی‌شوند.
- هیچ retry مبهمی بعد از ثبت یا پاسخ نامشخص انجام نمی‌شود.
- روند پیوست فقط ثبت، بارگذاری و تأیید اصالت را یک‌بار اجرا می‌کند و به‌صورت خودکار برای بارگذاری مجدد به منضمات بازنمی‌گردد.
- خطای هر مرحله اجرای همان اظهارنامه را متوقف می‌کند.
- عملیات زنده فقط با تأیید صریح اپراتور مجاز است.
- نتیجه و کد رهگیری باید کنار ورودی همان اظهارنامه ثبت شوند.

## اجرای تست‌ها

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
```

## تست ورود خودکاربری

وابستگی مرورگر را نصب کنید و فرمان زیر را اجرا کنید. اطلاعات ورود فقط از ورودی
مخفی ترمینال خوانده می‌شوند و در فایل یا آرگومان خط فرمان قرار نمی‌گیرند:

```powershell
python -m pip install -e ".[browser]"
sana-declaration-uploader login-check
```

این فرمان پس از مشاهدهٔ منوی اظهارنامه مرورگر را می‌بندد و هیچ اطلاعاتی در
سامانه ثبت نمی‌کند. timeout یا پاسخ مبهم باعث توقف می‌شود و retry ندارد.

## گام بعدی

گام بعدی، resolve کردن اطلاعات مخاطب از ابلاغیه و نگاشت بخش طرفین با مشاهدهٔ
زنده است. ثبت نهایی فقط پس از تثبیت شاهد کد رهگیری اضافه می‌شود.
